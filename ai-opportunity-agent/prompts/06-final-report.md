# Prompt 06: Final Recommendation Report

Act as a senior UX manager, AI product strategist, and enterprise SaaS consultant.

Generate an implementation-ready AI opportunity audit report using the previous outputs.

Report sections:

1. Executive summary
2. Product and user context
3. Current workflow audit
4. AI opportunity matrix
5. Recommended AI features
6. Human-in-the-loop model
7. Risk and governance matrix
8. MVP roadmap
9. Product/design/engineering implementation notes
10. Open questions

Writing style:

- clear
- business-ready
- practical
- evidence-based
- suitable for product, UX, engineering, and leadership

Rules:

- Separate high-confidence recommendations from assumptions.
- Make the first MVP recommendation explicit.
- Include what not to automate.
- Include success metrics.
- Include next 30/60/90 day plan.
