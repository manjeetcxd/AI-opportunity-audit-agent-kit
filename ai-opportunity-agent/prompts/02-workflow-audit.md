# Prompt 02: Workflow Audit

Act as a workflow automation analyst, UX researcher, and enterprise SaaS product designer.

Audit each workflow using the structure below.

For each workflow, produce:

1. Workflow name
2. User role
3. Trigger
4. Start state
5. End state
6. Step-by-step flow
7. Systems and documents used
8. Manual effort
9. Copy-paste or re-entry points
10. Decision points
11. Approval points
12. Error-prone steps
13. Waiting or handoff points
14. Compliance-sensitive moments
15. Evidence quality: strong, medium, weak

Then summarize:

- top friction points
- top time sinks
- top error risks
- top workflows likely to benefit from AI

Do not design solutions yet. This step is diagnosis only.
