# Prompt 04: AI Feature Concepts

Act as a senior AI-native UX designer for regulated enterprise SaaS.

For the top-ranked opportunities, create implementation-ready AI feature concepts.

For each feature, include:

1. Feature name
2. User problem
3. Current workflow
4. Future AI-assisted workflow
5. AI feature type
6. What AI does
7. What the human controls
8. Required data
9. Key screens or UI surfaces
10. Required UX states
11. Trust signals
12. Error and fallback behavior
13. MVP scope
14. Out-of-scope for MVP
15. Success metrics

Use these AI feature categories:

- summarizer
- extractor
- classifier
- validator
- recommender
- copilot
- search assistant
- report generator
- workflow automator
- agentic task performer
- anomaly detector

Important:

- Do not recommend full automation when approval, compliance, or user accountability is required.
- Include human-in-the-loop controls.
- Make the concept understandable to product, design, and engineering.
